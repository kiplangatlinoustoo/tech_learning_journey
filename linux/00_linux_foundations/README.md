# Linux Foundations

This section contains my foundational Linux studies.

The purpose of this stage is to become comfortable with the Linux command
line, understand the filesystem, work with files and directories, manage
permissions, inspect processes, understand the shell environment, and
eventually automate tasks using shell scripting.

# Primary Reference

*The Linux Command Line, 5th Edition  by William Shotts.

This repository does not reproduce the book. It contains my own
understanding, exercises, command examples, observations, and explanations
developed while studying the material.
