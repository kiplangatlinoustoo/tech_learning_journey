# Bash Learning Journey

Welcome to my Bash learning journey.

This directory documents my progress as I learn Bash from the fundamentals through practical scripting, system administration, and automation.

I am learning Bash as part of my transition from Customer Service and Operations into technology.

This is a hands-on learning repository. I am documenting not only what I learn, but also what I practice, the mistakes I make, the problems I solve, and what I understand along the way.

---

## How I Learn

Every chapter follows the same learning cycle:

**CONCEPT → WHY → COMMAND → BREAK IT DOWN → I PRACTICE → I EXPLAIN IT BACK**

The purpose is to understand rather than simply memorize.

Each topic contains:

- `README.md` — concepts and explanations
- `exercise.md` — hands-on practice
- `milestone.md` — lessons learned and reflection

Some chapters may also contain a practice directory for scripts and other hands-on work.
