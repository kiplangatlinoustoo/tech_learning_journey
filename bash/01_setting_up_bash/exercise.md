# Setting Up Bash - Exercises

## Objective

Practice verifying the Bash installation and creating your first Bash script.

---

# Exercise 1 - Check Bash Version

Run:

```bash
bash --version
```

Record your version below.

```
Version:
_____________________________
```

---

# Exercise 2 - Print a Message

Run:

```bash
echo "Learning Bash is fun!"
```

---

# Exercise 3 - Create a Script

Create a file.

```bash
touch hello.sh
```

---

# Exercise 4 - Edit the Script

Add the following:

```bash
#!/bin/bash

echo "Hello, Bash!"
```

---

# Exercise 5 - Execute the Script

Run:

```bash
bash hello.sh
```

Expected output:

```text
Hello, Bash!
```

---

# Challenge

Modify your script so it prints:

```text
Welcome to my Bash learning journey!
```

---

# Reflection

Answer the following:

- Why is it useful to know the Bash version?
- What is a Bash script?
- What is the purpose of the shebang?
- How can scripts save time?
