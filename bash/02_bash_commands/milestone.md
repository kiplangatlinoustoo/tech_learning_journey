# Milestone - 02 Bash Commands

## Chapter Completed

 Bash Commands

---

# Learning Objectives Achieved

After completing this chapter, I can:

- Display my current directory using `pwd`.
- List files with `ls`.
- Navigate directories using `cd`.
- Create directories with `mkdir`.
- Create files using `touch`.
- Display text with `echo`.
- Read files using `cat`.
- Copy files using `cp`.
- Rename or move files using `mv`.
- Delete files using `rm`.

---

# Key Concepts Learned

- Every Bash command performs a specific task.
- Commands can be combined to complete workflows.
- The terminal provides a fast and efficient way to manage files.
- Care must be taken when deleting files with `rm`.
