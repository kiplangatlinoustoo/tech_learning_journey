# Bash Commands - Exercises

## Objective

Practice the most common Bash commands used for navigating the filesystem and managing files.

---

## Exercise 1 - Check Your Location

```bash
pwd
```

Write the output below:

```
/root/learning_lab/tech_learning_journey/bash/02_bash_commands
```

---

## Exercise 2 - List Files

```bash
ls
```

Observe the files and directories displayed.

---

## Exercise 3 - Create a Directory

```bash
mkdir practice
```

Verify:

```bash
ls
```

---

## Exercise 4 - Enter the Directory

```bash
cd practice
```

Verify:

```bash
pwd
```

---

## Exercise 5 - Create Files

```bash
touch file1.txt
touch file2.txt
```

Verify:

```bash
ls
```

---

## Exercise 6 - Write Text

```bash
echo "Learning Bash Commands" > file1.txt
```

Display the contents.

```bash
cat file1.txt
```

---

## Exercise 7 - Copy a File

```bash
cp file1.txt backup.txt
```

Verify.

```bash
ls
```

---

## Exercise 8 - Rename a File

```bash
mv backup.txt notes.txt
```

Verify.

```bash
ls
```

---

## Exercise 9 - Delete a File

```bash
rm notes.txt
```

Verify.

```bash
ls
```

---

## Challenge

Without looking at your notes:

- Create a directory.
- Enter it.
- Create three files.
- Write text into one file.
- Display the contents.
- Copy a file.
- Rename a file.
- Delete one file.
