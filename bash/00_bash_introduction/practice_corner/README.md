# Practice Corner - 00 Bash Introduction

Hands-on scripts written while working through the concepts in this chapter. Each one builds slightly on the last.

| Script | Purpose |
|---|---|
| `bash_introduction.sh` | First script - print a simple greeting. |
| `bash_identity.sh` | Have the script describe what Bash is, in its own output. |
| `bash_version.sh` | Practice calling a real command (`bash --version`) from inside a script. |
| `bash_greeting.sh` | Practice producing multiple lines of output in sequence. |
| `bash_information.sh` | Combine everything above into one formatted script. |

## Running a script

```bash
bash script_name.sh
```

Or, after making it executable:

```bash
chmod +x script_name.sh
./script_name.sh
```

These scripts are intentionally simple. The goal at this stage is not complexity, it is building confidence with the basic `echo` command and the shebang (`#!/bin/bash`) before moving on to the advamced chapters.
